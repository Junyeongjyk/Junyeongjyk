# 👋 안녕하세요! 김준영입니다.

프론트엔드 역량을 중심으로 UI/UX를 주도적으로 구현하며, 
NestJS와 TypeORM을 활용해 필요한 서버 비즈니스 로직과 DB 테이블 구조(Migration)까지 안정적으로 연결하는 과정을 즐깁니다. 🌟

사용자 중심의 효율적인 화면과 탄탄한 데이터 흐름을 최우선으로 생각합니다. 😊

더 나은 웹 애플리케이션 경험을 위해 끊임없이 고민하고 성장하고 있습니다! 🚀
