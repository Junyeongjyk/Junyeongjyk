# 👋 안녕하세요! 프론트엔드 중심의 개발자 전준영입니다.

프론트엔드 역량을 바탕으로 UI/UX를 주도적으로 구현하며, NestJS와 TypeORM을 활용해 필요한 서버 비즈니스 로직과 데이터베이스 테이블 설계(Migration)까지 유연하게 다룰 수 있습니다. 
비즈니스 요구사항에 맞춰 화면과 서버 쿼리를 유기적으로 연결하고, 대용량 데이터 처리 및 성능 최적화에 몰입하는 과정을 즐깁니다.

- **소개:** 효율적인 비즈니스 데이터 관리를 위한 전사 관리자 대시보드 시스템
- **주요 기술:** React, NestJS, TypeScript, TypeORM, MySQL
- **핵심 경험:** 복잡하게 얽힌 관계형 비즈니스 데이터를 프론트엔드 화면에 직관적으로 시각화하고, 이를 뒷받침하기 위해 MVC 패턴 기반의 서버 쿼리 작성 및 데이터 연동

📌 **ERP System**
- **소개:** 수만 건의 대용량 비즈니스 데이터를 다루는 전사 자원 관리 시스템
- **주요 기술:** Svelte, NestJS, TypeScript, TypeORM, MySQL
- **핵심 경험:** TypeORM 마이그레이션을 통한 안정적인 테이블 구조 확장, 그리고 수만 건의 비즈니스 데이터 파싱 속도 최적화 및 클라이언트 사이드 메모리 과부하(브라우저 멈춤) 현상 해결
